Understand the form before you fill it.

What it does

Give FormSense a saved form page (or a public URL). It lists each field with what it means, what to enter, whether it is required and which document to have ready. Give it your planned answers and it checks length, format and options, and spots conflicts such as a national ID that does not match your birth date or gender.

Install

Windows

Install Python 3.9+ from python.org (tick "Add python.exe to PATH"), then in PowerShell:
py -m pip install git+https://github.com/mohamed-elshamy-ai/formsense
py -m pip install .
formsense form.html --answers answers.json
Untested. Should work (standard library only). Only tested on Linux.

macOS

Python 3.9+ (brew install python or python.org), then in Terminal:
python3 -m pip install git+https://github.com/mohamed-elshamy-ai/formsense
pip install .
formsense form.html --answers answers.json
Untested. Should work. Only tested on Linux.

Linux

Python 3.9+ is usually installed. In a terminal:
python3 -m pip install --user git+https://github.com/mohamed-elshamy-ai/formsense
pip install .
formsense form.html --answers answers.json
Tested. Tested on Linux (Python 3.10).

Android

Not available. Not available as an app or extension.

How it works

  1. It parses the form HTML and links each field to its label.
  2. Each field is matched against a hand-made table of common field types for its meaning and a document hint.
  3. Required comes from the form's own attribute or a * in the label; limits come from length, range, pattern, file types and options.
  4. With your answers it checks each value against those limits.
  5. It then compares answers with each other, for example the date inside an Egyptian national ID against your birth date.

Honest limits

  • Static HTML only: JavaScript-built forms, images, PDFs and multi-step forms are not read.
  • About 20 known field types. Others are reported as unknown. No AI model.
  • 'Required' comes from the page; server-side rules are invisible.
  • A short list of conflict rules. It cannot find contradictions in free text, and cannot tell if answers will be accepted.
  • Command line only: no browser extension yet.
